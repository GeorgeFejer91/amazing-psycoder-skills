## Phase 4: Set Sequence Structure

Now that the trial is defined (4 windows) and conditions are known (9 types, 50:50), determine sequence ordering and execution. Known from user's initial description: Practice loop × 20, 2 formal loops × 60.

Each sequence runs top-to-bottom. Window order within each sequence is left-to-right.

**Questions:**
1. "Feedback is only displayed during the practice phase, or is it also included in the formal experiment?"
2. "Is the sequence order fixed or balanced across subjects?"

### User: "Feedback is only for practice. The order is fixed."

Sequences complete:

```yaml
sequences:
  - name: Instructions
    order: 1
    window_ids: [Welcome]
    execution:
      mode: once

  - name: Exercise
    order: 2
    window_ids: [Fixation, Stroop, Feedback, ITI]
    execution:
      mode: loop
      repetitions: 20
    show_in: [practice]

  - name: Formal experiment_1
    order: 3
    window_ids: [Fixation, Stroop, ITI]
    execution:
      mode: loop
      repetitions: 60

  - name: Formal experiment_2
    order: 4
    window_ids: [Fixation, Stroop, ITI]
    execution:
      mode: loop
      repetitions: 60

  - name: End
    order: 5
    window_ids: [ThankYou]
    execution:
      mode: once
```
