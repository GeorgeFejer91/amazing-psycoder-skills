# One-way Between-subjects ANOVA

## Overview

One-way ANOVA between subjects is used to compare the mean differences of three or more independent samples.

**Typical scenario**: Comparison of the Stroop effect among three age groups and comparison of the effectiveness of three training programs.

## When to use

| Conditions | Requirements |
|------|------|
| Design | Between subjects, 3+ groups |
| DV | Continuous variable |
| Assumptions | Independent observations; the residual/variance structure of the chosen mean model is compatible with the inference method |

## Hypothesis and test

1. **Distribution/Influence Diagnosis**: Combines model residuals, sample structure and influence point evaluation without mechanical determination method of each group of Shapiro p-values
2. **Variance structure**: Pre-select regular or Welch/robust model; Levene can provide descriptive evidence, but does not make a data-driven switch
3. **Independence**: Different subjects in each group

## Effect size

η²p (eta squared) or ω² (omega squared). ω² is less biased than η²p and is preferred when reporting.

## Post hoc comparison

Post hoc or planned comparisons must first declare the claim family. Tukey, Holm/Bonferroni, hierarchical tests, or no correction each answer different comparison plans; you cannot automatically generate all pairwise comparisons just because the omnibus p-value is significant.

## R code

```r
library(tidyverse)
library(rstatix)
library(effectsize)

# --- Read data ---
# Long format: one column group (factor), one column score (continuous DV)
df <- read_csv("data.csv") |>
  mutate(group = factor(group))

# --- Descriptive statistics ---
df |>
  group_by(group) |>
  summarise(
    n    = n(),
    M    = mean(score),
    SD   = sd(score),
    .groups = "drop"
  )

# --- Main analysis ---
# The following two are not automatically selected from the Levene p-values on the same data; one is generated by the confirmed variance model.
model <- aov(score ~ group, data = df)
summary(model)

# Candidate implementation of heteroscedastic estimand/inference plan
oneway.test(score ~ group, data = df, var.equal = FALSE)

# --- Effect size ---
eta_squared(model, partial = FALSE)   # η²
omega_squared(model, partial = FALSE) # ω² (recommended correction value)

# --- Declared comparison family (only when config specifies all-pairwise Tukey) ---
TukeyHSD(model)

# or rstatix version (contains effect size, recommended for reporting)
df |>
  tukey_hsd(score ~ group) |>
  as_tibble()
```

## Report

APA 7th standard format:

> A one-way between-subjects ANOVA was conducted to compare the effect of **[IV]** on **[DV]** for **[Describe Three Groups + Groups]** .
>
> There was a [significant / non-significant] effect of **[IV]** on **[DV]** at the *p* < .05 level for the three conditions [*F*(*df*₁, *df*₂) = *F* value, *p* = *p* value, η² = .xx].
>
> Post hoc comparisons using the Tukey HSD test indicated that the mean score for **[ConditionA]** (*M* = *M* value, *SD* = *SD* value) was significantly [higher / lower / different] than **[Condition B]** (*M* = *M* value, *SD* = *SD* value), *p* = .xxx. [No other comparisons / …] were statistically significant.

## Alternative method
- **Welch ANOVA**: When the pre-stated estimand is consistent with the heteroscedastic mean model
- **Kruskal-Wallis**: When the target is rank/distribution difference and interpretation conditions such as independence and isomorphism apply; not "automatic replacement after normality test fails"
